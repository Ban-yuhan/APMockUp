v1.1 (2026-10-27) - 배치 시뮬레이터

배치 데이터 (게임)
- 맵 배치를 코드가 아닌 배치 데이터로 분리 (js/layout.js)
  - 맵 크기, 창고 내부, 구역, 벽
  - 시설 슬롯: 하차 주차공간, 하차장, 보관함, 포장대, 출고 도크(트럭 주차 위치 포함), 쓰레기통
  - 휴게실·알바 대기 구역 크기, 공기청정기 자리, 알바 출입구, 플레이어 시작 위치, 공정별 알바 대기 지점
  - 시설마다 위치, 방향, 해금 비용, 품목/목적지
- 게임이 배치를 읽는 순서: 시뮬레이터 테스트 플레이 → layout-data.js → 기본 배치
  - 오류가 있는 배치는 기본 배치로 대체하고 알림
- 상호작용 지점을 넣기/꺼내기/검수로 나눠 배치 가능
  - 같은 위치에 두면 하나의 범위로 합쳐짐, 따로 두면 범위도 따로
  - 알바도 공정에 맞는 지점으로 이동 (예: 이송 알바는 보관함 꺼내기 → 포장대 넣기)
- 트럭이 주차 방향에 맞춰 들어오고 나감
- 하차 주차공간 업그레이드 단계 수 = 배치의 주차공간 수
- 품목 목록을 배치 데이터에 포함 (이름, 이모지, 타입, 가격)
  - 게임은 배치의 품목 목록을 사용, 보관함 1개 = 품목 1종 유지

컨베이어 벨트
- 시설마다 벨트 포트(입구/출구)를 사람이 서는 상호작용 지점과 따로 둠
- 벨트를 라인 단위로 구성: 출발점 → 꺾이는 점 → 도착점, 한 방향으로만 흐름
- 라인 끝점을 다른 라인 위에 붙여 길 공유 (출발점 = 분기, 도착점 = 합류)
- 공정(분류/이송/출고분류)끼리는 길을 공유하지 않음
- 자동화 시 물품은 라인 방향을 따라 최단 경로로 이동, 연결이 없으면 직선 이동
- 기본 배치 벨트를 메인 라인 + 지선 구조로 변경
  (출고분류는 포장대에서 위로 모았다가 오른쪽 세로 라인으로 내려가 도크로 분기)

배치 시뮬레이터 (editor.html)
- 위에서 본 2D 편집 화면: 클릭 선택, 드래그 이동(격자 맞춤), 휠 확대, 화면 이동
- 맵 크기, 창고 내부 범위 조절
- 구역 추가/이동/크기 조절 (구역을 옮기면 안의 시설·벨트도 같이 이동, Alt+드래그는 구역만)
- 시설 추가/삭제/복제, 90도 회전 (상호작용 지점·벨트 포트·도크 트럭도 같이 회전)
- 속성 편집: 좌표, 방향, 품목, 목적지, 해금 비용, 주차공간·시설 순서
- 상호작용 지점 드래그로 분리/합치기, 범위가 겹치면 빨간 원으로 표시
- 벨트 라인 편집 (2·3·4 키로 공정 선택)
  - 출구 포트 클릭으로 새 라인, Alt+라인 클릭으로 지선, 입구 포트·다른 라인 클릭으로 연결
  - 꺾이는 점 추가/이동/삭제, 끝점 붙이기/떼기, 방향 뒤집기, 흐름 방향 화살표 표시
  - 자동 생성(초안): 메인 라인 1개 + 지선
  - 시설을 삭제하거나 순서를 바꾸면 벨트가 붙어 있던 시설 번호도 같이 정리
- 보관함·품목 추가
  - 보관함 추가 시 남는 품목이 없으면 새 품목을 같이 만듦 (복제도 같음)
  - 보관함 속성에서 품목 정보(이름/이모지/타입/가격) 바로 수정
  - 품목 관리 창: 품목 추가/수정/삭제, 보관함 없는 품목에 보관함 만들기
- 배치 검증: 오류(게임이 못 쓰는 배치)와 경고(범위·시설 겹침, 시작 해금 시설 없음,
  끊기거나 방향이 반대인 벨트, 보관함 없는 품목 등)
- 동선 측정: 트럭 → 하차장 → 보관함 → 포장대 → 도크 직선 평균 거리
- 되돌리기/다시하기, 자동 저장, 브라우저 저장 슬롯, JSON 내보내기/가져오기
- ▶ 테스트 플레이: 파일을 바꾸지 않고 현재 배치로 게임 실행
- 📦 layout-data.js 내보내기: 게임 폴더의 같은 파일을 덮어쓰면 게임 기본 배치로 반영
- 이전 형식으로 저장된 배치는 불러올 때 자동 변환 (벨트는 자동 생성 초안으로)
- 자체 점검 모드: editor.html?test

v1.0 (2026-10-26) - 게임 목업

기본 게임 (HTML + Three.js, index.html 더블클릭으로 실행)
- 택배 허브 관리자가 되어 하차 → 분류 → 검수 → 이송 → 포장 → 출고분류 → 상차를 처리
- 3D 기본 도형(큐브·원통·캡슐)과 이모지 표기, 고정 쿼터뷰 카메라, 휠 확대(확대 시 플레이어 추적)
- 조작: WASD·클릭 이동, 상호작용 범위 안에서 대기하면 자동 작업
  - 상호작용 범위를 바닥 원으로 표시, 플레이어 머리 위에 현재 범위와 하는 일(또는 못 하는 이유) 표시
  - 범위에 들어간 뒤 0.2초 후 작업 시작, 하차장은 들고 오면 내려놓기만·빈손이면 집기만
- 완전 샌드박스 (게임오버 없음), 저장 없음
- 맵을 넓게 쓰도록 배치하고 상호작용 범위끼리 겹치지 않게 조정

시설과 성장
- 고정 슬롯 해금: 보관함(품목), 포장대, 출고 도크(목적지)
- 공정별 업그레이드: Lv1~3 알바 배치 슬롯 1~3명, Lv4 자동화 (하차는 자동화 없음)
- 자동화: 분류·이송·출고분류 컨베이어, 검수·상차 기계손, 포장 기계
- 물류 시설 업그레이드: 하차 주차공간(입고 트럭 동시 대수), 하차장 크기, 보관함 최대 보관량
- 케어시설: 휴게실 티어(낡은 → 최고급), 공기청정기 (티어가 높을수록 화려해짐)

물류와 주문
- 주문서가 상단에 왼쪽부터 쌓이고 순서대로 처리, 화면에 안 보이는 주문은 '주문서 xN'으로 표시
- 입고 트럭은 섞인 물품을 싣고 옴, 해금된 품목만 배송
- 보관함 + 하차장 + 운송 중 물품의 합이 최대 보관량에 닿은 품목은 더 이상 배송되지 않음 (⛔ 표시)
- 검수 중 5% 불량, MT가 음수인 알바가 옮기면 파손 확률 → 쓰레기통에 버려야 함
- 주문 1건 = 포장 박스 1개, 박스 모양은 주문 품목 수로 결정

주야간과 이벤트
- 좌상단 시계에 낮/밤 표시, 기본 10분마다 전환
- 밤에는 창고 바깥만 어두워짐
- 명절 물류 폭주: 낮/밤 전환 시 확률 발동, 주문서가 한꺼번에 들어오고 그 시간대 동안 주문이 빨라짐

아르바이트
- 지원자 고용(이름, 힘/민첩/지능, 시급), 공정 7단계에 배치, 해고
- 스탯과 숙련도(들기/나르기/포장/검수)에 따라 픽업량·이동속도·작업속도 변화
- MT: 작업 1회당 2 감소, MT에 따른 휴식 확률, 휴게실에서 회복, 간식 드래그 앤 드롭으로 회복
  - 대부분의 시간 동안 MT가 0~20 사이에 머물도록 조정
- 시급은 1시간 단위, 낮/밤이 바뀔 때 12시간분 지급하고 알림에 소비 금액 표시
- 시급을 못 받으면 MT 감소 2배, 이후 낮/밤이 바뀔 때마다 도주 확률 상승

상차 미니게임 (차곡차곡 이식)
- 출고 트럭 앞에서 [E]로 패널을 열면 게임 시간 정지
- 트럭 짐칸 그리드에 포장 박스를 배치: 드래그 배치, R 키 또는 드래그 중 우클릭으로 회전, 좌클릭 드래그 이동, 우클릭 회수, 초기화
- 트럭 종류별 짐칸 크기 (소형 5x4, 중형 5x5, 대형 6x5), 잠긴 칸은 트럭마다 개수·위치 랜덤
- 적재율: 모든 칸을 채우면 200%, 구간별 정산 배율 (100% x1.0 · 150% x1.2 · 200% x1.5)
- 타입 랭크(E~S): 혼합 박스는 들어간 타입마다 1개씩 계산, 랭크 배율 적용
- 특수 목표(서브미션) 1~5개: 달성하면 체크, 박스를 빼면 해제
  - 달성 보너스는 적재율에 더해지며 200% 상한을 넘을 수 있음 (초과 1%p당 배율 +0.01)
- 미니게임 업그레이드: 압축 적재(겹쳐 놓기), 우선 적재 칸(보너스 칸)
- 출발 버튼으로 출발, 알바·자동화 상차는 고정 적재율로 자동 출발
- 패널은 고정 크기 (1180 x 720)

디버그 패널 (🛠️ 디버그 버튼 또는 ` 키)
- 돈 1,000원 단위 추가/차감, 낮/밤 강제 전환(시급·이벤트 판정 포함/제외), +1시간
- 이벤트 강제 발동/종료, 주문서 추가/비우기, 입고·출고 트럭 즉시 호출
- 알바 MT 일괄 변경, 지원자 새로고침, 모든 시설 해금
- 배속 (일시정지 / x1 / x2 / x4)
