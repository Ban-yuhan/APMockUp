택배 허브를 총괄하는 관리자가 되는 게임
관리자(플레이어)는 허브의 모든 일을 함과 동시에 알바, 시설을 관리 한다.

기본골자
택배 받기 -> 택배 분류 -> 택배 검수 -> 택배 상차

1. 트럭에서 택배를 하차한다. 
작업: 트럭앞에서 대기
자동화: X

2. 하차한 택배를 분류한다. (재고 채우기) 
작업: 택배를 들고 분류 알맞은 보관함으로 이동
자동화: 컨베이어 벨트로 자동 분류

3. 분류한 택배를 검수한다. (불량품이 없는지) 
작업: 보관함 옆에서 대기(1.s)
자동화: 기계손이 자동 검수

4. 요청(주문서)에 따라 포장대로 물품 이송 
작업: 보관함에서 포장대까지 이송
자동화: 컨베이어 벨트로 주문서의 물품 이송

5. 모든 물품이 이송되었으면 포장 
작업: 포장대 앞에서 대기(1.s)
자동화: 포장 기계에 물품이 들어갔다 나오면 포장 완료

6. 포장된 물품을 알맞은 출고장소(서울,대구,부산,인천...) 트럭 앞으로 분류 
작업: 포장대에서 트럭앞으로 물품 이송
자동화: 컨베이어 벨트로 물품 이송

7. 분류된 물건을 트럭으로 상차
작업: 분류된 물품을 트럭안으로 이송 (차곡차곡 미니게임)
자동화: 기계손이 물품을 트럭안으로 이송

=======================================================================

시설

작업시설
1. 보관함
-> 물품을 보관하는 장소 그리드 형식으로 배치되어있다.
컨베이어 벨트로 이어질것을 고려한 배치
2. 포장대
-> 보관함에서 오는 물품들을 포장하는 장소 보관함과 일정간격 떨어져 있음
포장 시설 증가와 컨베이어 벨트 연결을 고려한 배치

케어시설(Tier: 낡은, 평범한, 고급, 최고급 )
티어가 높을수록 화려해짐
1. 휴계실
-> 낡은 휴계실로 시작
-> 직원들은 작업후 현재 MT에 따라 휴식확률이 생김, MT가 낮을수록 휴식확률이 증가(ex. -100~-50: 50%, -50~0: 30%, 0 ~ 20: 10%, 20~100: 2%)
2. 공기청정기
-> 돈을 지불해 배치해야함
-> 일정확률로 알바가 MT감소 없이 작업한다.

아르바이트

고용 
알바의 이름, 기본 스텟, 시급을 확인 할 수 있음
고용시 대기중 알바 슬롯에 들어감
시급을 낼 수 없다면 알바의 작업당 감정수치가 2배로 빠르게 떨어진다. 
이후 주 야간이 바뀌는날 도망갈 확률이 10%씩 상승한다.

배치
사장이 원하는 장소에 배치 기본1명에 시설 업그레이드시 배치슬롯 1개씩 추가
자동화(최종업그레이드) 시 배치된 알바는 대기중 슬롯으로 이동

기본스텟
힘 -> 1당 최대 픽업량 증가
민첩 -> 1당 이동속도 증가
지능 -> 1당 작업속도 증가

숙련도
작업목록 마다 숙련도 파라미터가 있음
숙련도는 각행동에 의해 영향이 나타남
기본스텟에 따라 숙련도 증가량이 달라진다(ex. 힘이 높은 경우 물건들기 작업시 숙련도 배율이 높다.)
물건 들기 -> 최대 픽업량
물건 나르기 -> 이동속도
물건 포장 -> 포장 작업속도
물건 검수 -> 검수 작업속도

감정수치(가명 멘탈(MT))
MT에 따라 작업 능률에 변화가 생긴다(이속 증감, ~ 작업속도 증감)
물류 이송시 물류 파손확률이 생김(5%)
MT의 증가: 휴식공간에서 휴식, 플레이어의 간식주기
MT의 감소: 작업 1회당 1씩 감소(물건 최대량 or 필요한 만큼 들기 = 1회, 물품 검수 = 1회,  )

휴식
휴계장소로 이동해 휴식을 취하며 MT를 회복한다.

간식주기
오른쪽 Ui에서 간식을 알바에게 드래그앤 드롭해 MT를 회복한다.
현재 간식은 별도구매장소없음 그냥 무제한제공(목업이니까)

물류

물류는 트럭에서 섞여 제공된다. 
(보관함이 있는것만 배송해줌(ex. 휴지 품목 보관함 미해금인데 휴지 품목을 배송해 주지는 않는다.))

파손된 물류
검수중 5%확률로 생기거나 MT가 음수가 된 알바생이 물류 이송 작업을 한다면 파손확률이 생긴다.
파손시 맵 하단의 쓰레기통에 버려야함
